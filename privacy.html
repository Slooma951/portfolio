Portfolio privacy

Updated 3 October 2026.

This portfolio is a static site hosted through GitHub Pages. The portfolio's own pages have no contact form, account system or analytics script.

Theme preference

If you change the colour theme, the site saves that preference in your browser's local storage. You can clear it through your browser's site-data settings.

Hosting and external links

GitHub processes requests to serve the site under its own privacy practices. Links to LinkedIn, GitHub and the Chrome Web Store take you to services with their own policies.

Product policies

Scribevo is a separate product. Read its privacy policy for sentence processing and provider information. The portfolio's privacy description is not a policy for the private desktop project.
